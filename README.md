Overview
🌟 Radha-Krishna Eduquest
Radha-Krishna Eduquest is an atmospheric, educational infinite runner web game designed for curious minds in classes 9–12. Set along a peaceful, moonlit river path in Vrindavan after dusk, the project beautifully blends gameplay with academic learning—letting knowledge light the path as players run, jump, and slide.
🎮 Game Features
• Atmospheric Setting: Immersive visuals featuring a moonlit path along the Yamuna river, complete with distant temple forms and silhouette trees.
• Curriculum-Focused Q&A: Academic questions adapt based on the player's selected class level (Class 9 through Class 12).
• Dynamic Milestones: Progressing through the infinite runner fills a distance meter that triggers quiz checkpoints.
• Engaging Mechanics: Includes fluid movement, a live score/highscore system, level progression, and life tracking.
• Pause & Resume: Built-in progression state safety allowing players to freeze the run, catch a breath, and resume seamlessly.
🕹️ Controls
• ↑ Arrow / W: Jump over hurdles
• ↓ Arrow / S: Slide under obstacles
• ← / → Arrows: Move left and right
• Esc: Pause / Resume the game
🛠️ Tech Stack
• Frontend: HTML5, CSS3, JavaScript (ES6+)
• Graphics: HTML5 Canvas API for real-time rendering and fluid character animation
